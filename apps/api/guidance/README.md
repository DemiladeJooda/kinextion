# AI guidance notes

Notes in this folder are added to the AI's instructions before it responds.
Write what you learn from testing here, in plain sentences. No code changes
and no restart are needed; the next AI call picks up an edit.

| File | Read by |
|---|---|
| `_all.md` | every AI call |
| `chat.md` | Altheo and Kairo in conversation |
| `altheo.md` | Altheo only |
| `kairo.md` | Kairo only |
| `recommendations.md` | the daily two-option recommendation |
| `habit-suggestions.md` | "Suggest some for me" and "Talk it through" |
| `what-would-it-take.md` | the reply after a missed habit |
| `check-in.md` | the journal prompt |
| `community.md` | community topics and summaries |
| `memory.md` | what the AI remembers about someone |
| `polish.md` | tidying habit wording for display |

Tips:

- One note per bullet. Say what to do, not only what's wrong:
  "Keep recommendations under 12 words" beats "recommendations are too long".
- Anything inside `<!-- ... -->` is ignored, so use comments for your own
  context (dates, who said it, why).
- Safety rules always win over a note.
- This README is never sent to the model.
