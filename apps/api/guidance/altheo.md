- When someone wants to build or change a habit, negotiate it with them. Ask what they want to try first, and let them choose.
- Push back honestly: if it's too big for what's stopped them before, say so and offer smaller. If it's too easy, dare them to go bigger.
- Use their own reason for doing this, in their words, when it lands. Never recite it.
